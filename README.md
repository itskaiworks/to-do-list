# To-Do List

A Flutter-based task management application developed as part of Finals Laboratory Activity 1. It demonstrates the implementation of task management, user interactions, and basic application logic using Dart and Flutter.

---

## Overview

To-Do List is a task management application designed to help users organize their daily responsibilities and stay productive. It demonstrates the implementation of Flutter widgets, user interactions, and basic application logic in developing a functional task management interface.

## Features

- **Task Management** – Allows users to create and manage tasks.
- **Task Completion** – Provides a way to identify completed and pending tasks.
- **Task Organization** – Presents tasks in an organized list.
- **Interactive Interface** – Uses Flutter widgets to support user interactions.
- **User-Friendly Design** – Provides a straightforward interface for managing daily activities.

## Technologies Used

- **Flutter** – Application development framework
- **Dart** – Primary programming language
- **Material Design** – UI components and design elements
- **Git & GitHub** – Version control and source code hosting
